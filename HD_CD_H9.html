💿 Bài 8 – OOP: Quản lý CD (Mảng tự động mở rộng)

CRUD đầy đủ: Thêm – Xóa – Sửa – Cập nhật – Tìm kiếm – Thống kê – Sắp xếp

📌 1. Mô tả bài toán

Lớp đối tượng CD gồm:

  • Mã CD (int > 0, mặc định 999999)
  • Tựa CD (chuỗi không rỗng, mặc định "chua xac dinh")
  • Số bài hát (int > 0)
  • Giá thành (double > 0)

Yêu cầu:

  1. Viết lớp CD với getter/setter kiểm tra ràng buộc, constructor, toString.
  2. Viết lớp CDList dùng mảng nguyên thủy:
    • Tự động mở rộng mảng khi đầy (không giới hạn MAX cứng).
    • Thêm CD (không cho trùng mã).
    • Xóa CD theo mã.
    • Sửa (cập nhật) tựa CD, số bài hát, giá thành theo mã.
    • Tìm kiếm theo mã hoặc theo tựa.
    • Thống kê: số lượng, tổng giá thành, giá trung bình, CD đắt nhất, CD rẻ nhất.
    • Sắp xếp giảm dần theo giá, tăng dần theo tựa CD.
  3. Viết lớp Main với menu case thực hiện tất cả chức năng.
💡 Điểm mới: Khi mảng đầy, ta tạo mảng mới có kích thước gấp đôi và sao chép toàn bộ dữ liệu cũ sang → không bao giờ tràn mảng.

🧠 2. Phân tích thiết kế

2.1. Cơ chế mở rộng mảng động

Ban đầu mảng có kích thước khaNang = 10. Khi soLuong == khaNang, ta:

  1. Tạo mảng mới có kích thước khaNang * 2.
  2. Dùng vòng lặp sao chép từng phần tử từ mảng cũ sang mảng mới.
  3. Gán mảng mới cho danhSachCD và cập nhật khaNang.

Nhờ vậy, chương trình không bao giờ hết chỗ chứa CD.

2.2. Kiểm tra trùng mã

Trước khi thêm, duyệt mảng tìm maCD trùng. Nếu có → từ chối thêm.

2.3. Xóa phần tử

Tìm vị trí cần xóa, sau đó dịch các phần tử phía sau sang trái 1 ô và giảm soLuong.

2.4. Sửa / Cập nhật

Tìm theo mã, sau đó gọi setter để cập nhật từng thuộc tính (tựa, số bài, giá). Mã CD không sửa.

2.5. Thống kê

  • Số lượng CD hiện có.
  • Tổng giá thành.
  • Giá trung bình.
  • CD đắt nhất, CD rẻ nhất.

// ========== File 1: CD.java ==========
public class CD {
    // ---------- Thuộc tính (private) ----------
    private int maCD;
    private String tuaCD;
    private int soBaiHat;
    private double giaThanh;

    // ---------- Hằng số mặc định ----------
    public static final int MA_CD_MAC_DINH = 999999;
    public static final String TUA_CD_MAC_DINH = "chua xac dinh";

    // ---------- Constructor mặc định ----------
    public CD() {
        this.maCD = MA_CD_MAC_DINH;
        this.tuaCD = TUA_CD_MAC_DINH;
        this.soBaiHat = 1;
        this.giaThanh = 1.0;
    }

    // ---------- Constructor có tham số ----------
    public CD(int maCD, String tuaCD, int soBaiHat, double giaThanh) {
        setMaCD(maCD);
        setTuaCD(tuaCD);
        setSoBaiHat(soBaiHat);
        setGiaThanh(giaThanh);
    }

    // ---------- Getter ----------
    public int getMaCD() { return maCD; }
    public String getTuaCD() { return tuaCD; }
    public int getSoBaiHat() { return soBaiHat; }
    public double getGiaThanh() { return giaThanh; }

    // ---------- Setter có kiểm tra ràng buộc ----------
    public void setMaCD(int maCD) {
        if (maCD <= 0)
            throw new IllegalArgumentException("Lỗi: Mã CD phải > 0!");
        this.maCD = maCD;
    }

    public void setTuaCD(String tuaCD) {
        if (tuaCD == null || tuaCD.trim().isEmpty())
            throw new IllegalArgumentException("Lỗi: Tựa CD không được rỗng!");
        this.tuaCD = tuaCD;
    }

    public void setSoBaiHat(int soBaiHat) {
        if (soBaiHat <= 0)
            throw new IllegalArgumentException("Lỗi: Số bài hát phải > 0!");
        this.soBaiHat = soBaiHat;
    }

    public void setGiaThanh(double giaThanh) {
        if (giaThanh <= 0)
            throw new IllegalArgumentException("Lỗi: Giá thành phải > 0!");
        this.giaThanh = giaThanh;
    }

    // ---------- toString định dạng bảng ----------
    @Override
    public String toString() {
        return String.format(
            "| %-10d | %-25s | %-12d | %-15.2f |",
            maCD, tuaCD, soBaiHat, giaThanh);
    }
}

// ========== File 2: CDList.java (Mảng tự mở rộng + CRUD đầy đủ) ==========
public class CDList {
    // ---------- Thuộc tính ----------
    private CD[] danhSachCD;      // mảng động
    private int soLuong;           // số phần tử hiện có
    private int khaNang;            // sức chứa hiện tại của mảng

    private static final int KICH_THUOC_BAN_DAU = 5;

    // ---------- Constructor khởi tạo ----------
    public CDList() {
        khaNang = KICH_THUOC_BAN_DAU;
        danhSachCD = new CD[khaNang];
        soLuong = 0;
    }

    // ---------- Tự động mở rộng mảng khi đầy ----------
    private void moRongMang() {
        int kichThuocMoi = khaNang * 2;
        CD[] mangMoi = new CD[kichThuocMoi];
        // Sao chép dữ liệu cũ sang mảng mới
        for (int i = 0; i < soLuong; i++) {
            mangMoi[i] = danhSachCD[i];
        }
        danhSachCD = mangMoi;
        khaNang = kichThuocMoi;
        System.out.println("📈 Đã mở rộng mảng lên " + khaNang + " phần tử.");
    }

    // ---------- Tìm vị trí CD theo mã (trả về -1 nếu không có) ----------
    public int timViTriTheoMa(int maCD) {
        for (int i = 0; i < soLuong; i++) {
            if (danhSachCD[i].getMaCD() == maCD)
                return i;
        }
        return -1;
    }

    // ========== THÊM ==========
    // Trả về true nếu thêm thành công, false nếu trùng mã
    public boolean themCD(CD cd) {
        // Kiểm tra trùng mã
        if (timViTriTheoMa(cd.getMaCD()) != -1) {
            System.out.println("❌ Lỗi: Mã CD " + cd.getMaCD() + " đã tồn tại!");
            return false;
        }
        // Nếu mảng đầy -> mở rộng
        if (soLuong == khaNang) {
            moRongMang();
        }
        danhSachCD[soLuong] = cd;
        soLuong++;
        return true;
    }

    // ========== XÓA ==========
    public boolean xoaCD(int maCD) {
        int viTri = timViTriTheoMa(maCD);
        if (viTri == -1) {
            System.out.println("❌ Không tìm thấy CD có mã " + maCD);
            return false;
        }
        // Dịch các phần tử phía sau sang trái
        for (int i = viTri; i < soLuong - 1; i++) {
            danhSachCD[i] = danhSachCD[i + 1];
        }
        danhSachCD[soLuong - 1] = null;
        soLuong--;
        return true;
    }

    // ========== SỬA / CẬP NHẬT ==========
    // Cập nhật thông tin CD theo mã (không sửa mã CD)
    public boolean capNhatCD(int maCD, String tuaMoi,
                             int soBaiMoi, double giaMoi) {
        int viTri = timViTriTheoMa(maCD);
        if (viTri == -1) {
            System.out.println("❌ Không tìm thấy CD có mã " + maCD);
            return false;
        }
        CD cd = danhSachCD[viTri];
        cd.setTuaCD(tuaMoi);
        cd.setSoBaiHat(soBaiMoi);
        cd.setGiaThanh(giaMoi);
        return true;
    }

    // ========== TÌM KIẾM ==========
    public CD timTheoMa(int maCD) {
        int viTri = timViTriTheoMa(maCD);
        return (viTri == -1) ? null : danhSachCD[viTri];
    }

    // Tìm theo tựa CD (chứa chuỗi con, không phân biệt hoa thường)
    public void timTheoTua(String tuKhoa) {
        boolean timThay = false;
        System.out.println("\n🔍 Kết quả tìm kiếm với từ khóa '" + tuKhoa + "':");
        for (int i = 0; i < soLuong; i++) {
            if (danhSachCD[i].getTuaCD().toLowerCase()
                    .contains(tuKhoa.toLowerCase())) {
                System.out.println(danhSachCD[i]);
                timThay = true;
            }
        }
        if (!timThay) System.out.println("Không có CD nào phù hợp.");
    }

    // ========== THỐNG KÊ ==========
    public int tinhSoLuongCD() {
        return soLuong;
    }

    public double tinhTongGiaThanh() {
        double tong = 0;
        for (int i = 0; i < soLuong; i++)
            tong += danhSachCD[i].getGiaThanh();
        return tong;
    }

    public double tinhGiaTrungBinh() {
        if (soLuong == 0) return 0;
        return tinhTongGiaThanh() / soLuong;
    }

    public CD timCDDatNhat() {
        if (soLuong == 0) return null;
        CD max = danhSachCD[0];
        for (int i = 1; i < soLuong; i++)
            if (danhSachCD[i].getGiaThanh() > max.getGiaThanh())
                max = danhSachCD[i];
        return max;
    }

    public CD timCDReNhat() {
        if (soLuong == 0) return null;
        CD min = danhSachCD[0];
        for (int i = 1; i < soLuong; i++)
            if (danhSachCD[i].getGiaThanh() < min.getGiaThanh())
                min = danhSachCD[i];
        return min;
    }

    // ========== HIỂN THỊ ==========
    public void hienThiDanhSach() {
        if (soLuong == 0) {
            System.out.println("📭 Danh sách CD trống!");
            return;
        }
        System.out.println("\n+------------+---------------------------+--------------+-----------------+");
        System.out.println("|   Mã CD    |          Tựa CD           |  Số bài hát  |    Giá thành    |");
        System.out.println("+------------+---------------------------+--------------+-----------------+");
        for (int i = 0; i < soLuong; i++)
            System.out.println(danhSachCD[i]);
        System.out.println("+------------+---------------------------+--------------+-----------------+");
    }

    // ========== SẮP XẾP ==========
    // Giảm dần theo giá thành (Bubble Sort)
    public void sapXepGiamDanTheoGia() {
        for (int i = 0; i < soLuong - 1; i++) {
            for (int j = i + 1; j < soLuong; j++) {
                if (danhSachCD[i].getGiaThanh() < danhSachCD[j].getGiaThanh()) {
                    CD temp = danhSachCD[i];
                    danhSachCD[i] = danhSachCD[j];
                    danhSachCD[j] = temp;
                }
            }
        }
        System.out.println("✅ Đã sắp xếp giảm dần theo giá thành.");
    }

    // Tăng dần theo tựa CD (không phân biệt hoa thường)
    public void sapXepTangDanTheoTua() {
        for (int i = 0; i < soLuong - 1; i++) {
            for (int j = i + 1; j < soLuong; j++) {
                if (danhSachCD[i].getTuaCD()
                        .compareToIgnoreCase(danhSachCD[j].getTuaCD()) > 0) {
                    CD temp = danhSachCD[i];
                    danhSachCD[i] = danhSachCD[j];
                    danhSachCD[j] = temp;
                }
            }
        }
        System.out.println("✅ Đã sắp xếp tăng dần theo tựa CD.");
    }
}

// ========== File 3: Main.java (Menu đầy đủ chức năng) ==========
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        CDList ql = new CDList();
        int luaChon = -1;

        do {
            System.out.println("\n╔═════════════ MENU QUẢN LÝ CD ═════════════╗");
            System.out.println("║  1. Thêm CD (tự mở rộng mảng khi đầy)     ║");
            System.out.println("║  2. Xóa CD theo mã                        ║");
            System.out.println("║  3. Sửa / Cập nhật CD theo mã             ║");
            System.out.println("║  4. Tìm kiếm theo mã                      ║");
            System.out.println("║  5. Tìm kiếm theo tựa (từ khóa)           ║");
            System.out.println("║  6. Hiển thị danh sách                    ║");
            System.out.println("║  7. Thống kê (số lượng, tổng, TB, max, min)║");
            System.out.println("║  8. Sắp xếp giảm dần theo giá thành       ║");
            System.out.println("║  9. Sắp xếp tăng dần theo tựa CD          ║");
            System.out.println("║  0. Thoát                                 ║");
            System.out.println("╚═══════════════════════════════════════════╝");
            System.out.print("👉 Chọn chức năng: ");

            try {
                luaChon = Integer.parseInt(sc.nextLine());
            } catch (NumberFormatException e) {
                System.out.println("⚠️ Vui lòng nhập số!");
                continue;
            }

            switch (luaChon) {
                case 1:
                    try {
                        System.out.print("Nhập mã CD (>0): ");
                        int ma = Integer.parseInt(sc.nextLine());
                        System.out.print("Nhập tựa CD: ");
                        String tua = sc.nextLine();
                        System.out.print("Nhập số bài hát (>0): ");
                        int sbh = Integer.parseInt(sc.nextLine());
                        System.out.print("Nhập giá thành (>0): ");
                        double gia = Double.parseDouble(sc.nextLine());

                        if (ql.themCD(new CD(ma, tua, sbh, gia)))
                            System.out.println("✅ Thêm CD thành công!");
                    } catch (Exception e) {
                        System.out.println(e.getMessage());
                    }
                    break;

                case 2:
                    try {
                        System.out.print("Nhập mã CD cần xóa: ");
                        int maXoa = Integer.parseInt(sc.nextLine());
                        if (ql.xoaCD(maXoa))
                            System.out.println("🗑️ Đã xóa CD mã " + maXoa);
                    } catch (NumberFormatException e) {
                        System.out.println("⚠️ Mã phải là số nguyên!");
                    }
                    break;

                case 3:
                    try {
                        System.out.print("Nhập mã CD cần sửa: ");
                        int maSua = Integer.parseInt(sc.nextLine());
                        System.out.print("Tựa CD mới: ");
                        String tuaMoi = sc.nextLine();
                        System.out.print("Số bài hát mới: ");
                        int sbhMoi = Integer.parseInt(sc.nextLine());
                        System.out.print("Giá thành mới: ");
                        double giaMoi = Double.parseDouble(sc.nextLine());

                        if (ql.capNhatCD(maSua, tuaMoi, sbhMoi, giaMoi))
                            System.out.println("✅ Đã cập nhật CD mã " + maSua);
                    } catch (Exception e) {
                        System.out.println(e.getMessage());
                    }
                    break;

                case 4:
                    try {
                        System.out.print("Nhập mã CD cần tìm: ");
                        int maTim = Integer.parseInt(sc.nextLine());
                        CD kq = ql.timTheoMa(maTim);
                        if (kq != null) {
                            System.out.println("🔍 Tìm thấy:");
                            System.out.println(kq);
                        } else {
                            System.out.println("❌ Không có CD mã " + maTim);
                        }
                    } catch (NumberFormatException e) {
                        System.out.println("⚠️ Mã phải là số!");
                    }
                    break;

                case 5:
                    System.out.print("Nhập từ khóa tựa CD: ");
                    String tk = sc.nextLine();
                    ql.timTheoTua(tk);
                    break;

                case 6:
                    ql.hienThiDanhSach();
                    break;

                case 7:
                    System.out.println("\n===== THỐNG KÊ =====");
                    System.out.println("📊 Số lượng CD: " + ql.tinhSoLuongCD());
                    System.out.printf("💰 Tổng giá thành: %,.2f VNĐ\n", ql.tinhTongGiaThanh());
                    System.out.printf("📈 Giá trung bình: %,.2f VNĐ\n", ql.tinhGiaTrungBinh());
                    CD max = ql.timCDDatNhat();
                    CD min = ql.timCDReNhat();
                    if (max != null) {
                        System.out.println("💎 CD đắt nhất:");
                        System.out.println("   " + max);
                        System.out.println("💵 CD rẻ nhất:");
                        System.out.println("   " + min);
                    }
                    break;

                case 8:
                    ql.sapXepGiamDanTheoGia();
                    ql.hienThiDanhSach();
                    break;

                case 9:
                    ql.sapXepTangDanTheoTua();
                    ql.hienThiDanhSach();
                    break;

                case 0:
                    System.out.println("👋 Tạm biệt!");
                    break;

                default:
                    System.out.println("⚠️ Lựa chọn không hợp lệ!");
            }
        } while (luaChon != 0);

        sc.close();
    }
}

✅ 5. Tổng kết kiến thức

Chức năng Phương thức Kỹ thuật
Thêm CD (chống trùng) themCD() Duyệt mảng + tự mở rộng
Xóa CD theo mã xoaCD() Dịch trái phần tử
Sửa / Cập nhật capNhatCD() Tìm + setter
Tìm theo mã / tựa timTheoMa(), timTheoTua() Duyệt tuần tự
Thống kê tinhSoLuongCD(), tinhTongGiaThanh()... Vòng lặp tích lũy
Sắp xếp sapXepGiamDanTheoGia(), ... Bubble Sort
Mở rộng mảng moRongMang() Nhân đôi kích thước + copy
💡 Mẹo: Cơ chế mở rộng mảng gấp đôi giúp giảm số lần cấp phát bộ nhớ, đạt độ phức tạp trung bình O(1) cho thao tác thêm — giống cơ chế của ArrayList trong Java.
